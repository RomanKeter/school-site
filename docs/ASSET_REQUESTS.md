# Заявки на картинки

Очередь графики для предметных групп. Картинки стиля 3: объёмный «игровой» 3D (мягкий пластилин/винил), приглушённая палитра, WebP внутри SVG-обёртки.

**Имена файлов (D-050).** Слова: `static/img/words/<слово в нижнем регистре>.svg` — ровно так, как шаблон `{{ word.word|lower }}` (пробелы и апостроф сохраняем, код шаблонов не меняем). Значки: `static/img/badges/<badge.code>.svg`.

**Статусы:** `нужно` · `в работе` · `готово` · `не требуется`.

**Повторный просмотр.** Список обновляется после обхода веток `stage2-en`, `stage2-math`, `stage2-ru`, `stage3-by`. Worktree белорусского: `/workspace/school-site/app-by`.
