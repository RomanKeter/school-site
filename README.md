# Учебный сайт для ученицы 5 класса — MVP (Этап 1)

Веб-сайт для ежедневных 15-минутных занятий по **математике** и **английскому** (5 класс, программа Беларуси).
Персонаж-наставник — зубр **Зубрик**. Ошибки не ругаются: ребёнок получает подсказку и пробует снова.
ТЗ: [`docs/TZ_uchebny_sait.md`](docs/TZ_uchebny_sait.md).

* **Журнал решений:** [`DECISIONS.md`](DECISIONS.md). Каждое решение записано с причиной, отклонёнными вариантами и затронутыми файлами.
* **Журнал работ:** [`WORKLOG.md`](WORKLOG.md). Хронология шагов и проверок.
* **Передача контекста чата:** [`docs/KALKA_chata.md`](docs/KALKA_chata.md).

## Стек

* Django 5.2 (Python 3.12+).
* HTMX 2: фрагменты страниц без SPA. Все файлы лежат локально, внешние домены запрещены CSP.
* PostgreSQL в проде, SQLite для локального запуска (выбор через `DATABASE_URL`).
* Пароли хешируются Argon2. Картинный пароль ребёнка тоже хранится как хеш.
* Тесты: pytest, pytest-django, hypothesis. E2E и скриншоты: Playwright + Chrome.

## Быстрый запуск локально

```bash
cd app
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo        # контент + демо-семья + админ
python manage.py demo_progress    # (по желанию) 2 недели истории: звёзды, серия, повторения
python manage.py runserver 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000.

| Кто | Вход | Данные |
|---|---|---|
| Ребёнок | «Я ученик» → Алеся → картинки | 🍎 🐱 ⭐ ⚽ |
| Родитель | «Я родитель» | `roman` / `ChildPass123!` |
| Админ | http://127.0.0.1:8000/admin/ | `admin` / `AdminPass123!` |

> Тихие часы по умолчанию начинаются в 21:00 по Минску. После этого времени ребёнок увидит «Зубрик спит».
> Чтобы проверить сайт вечером, поменяйте время в «Настройки» на странице родителя.

## Что работает

**Вход и семья.**
* Родитель входит по логину и паролю.
* Ребёнок выбирает свою аватарку и вводит пароль из 4 картинок. После 5 неудачных попыток вход блокируется на 5 минут.
* Ребёнок может входить только с доверенного устройства. Устройство отмечает родитель (подписанная cookie на 180 дней).
* Родитель может добавить ребёнка.

**Диагностика.** При первом входе ребёнок проходит короткий входной тест. Он определяет стартовые навыки, и после него сразу собирается обычная миссия.

**Миссия дня на ~15 минут** состоит из шагов:
1. Разминка.
2. «Повторим» по интервальному повторению, с перемешиванием тем (interleaving).
3. Урок по текущему навыку: разобранный пример, затем адаптивные задания.
4. Новые английские слова.
5. «Сюрприз».

**Задания.** 13 типов: выбор ответа, ввод числа или текста с экранной клавиатурой, сопоставление, сортировка по группам, упорядочивание, «собери слово из букв», карточка слова, выбор картинки, пропуск в предложении, верно/неверно, пошаговое решение, дробь с визуальной моделью, «весы» и столбиковая модель.

**Обратная связь и подсказки.**
* Фразы подобраны так, чтобы не стыдить ребёнка. После 1-й ошибки — «попробуй иначе».
* Со 2-й попытки подсказки (до 3 уровней) появляются автоматически.
* После 3 попыток ребёнок видит разбор, ответ и «+1 ★ за упорство».

**Мастерство.**
* Считается по последним 10 ответам с весами (без подсказки 1, с подсказкой 0,7, после разбора 0,4).
* Навык освоен при ≥ 80 %, если ответов не меньше 8 и они даны минимум в 2 разных дня.
* Статусы: «учу», «почти», «освоено», «пора освежить».

**Адаптивность.**
* 3 верных ответа подряд — уровень сложности повышается.
* 2 ошибки подряд — уровень понижается. Ребёнку об этом не сообщается.

**Интервальное повторение.**
* Модифицированный SM-2 с интервалами 1 → 3 → 7 → …, не дольше 60 дней.
* К длинным интервалам добавляется разброс ±10 %.
* Для просроченных карточек засчитывается половина пропущенного срока.
* Интервал меняет только первый ответ дня. Неверную карточку ребёнок ещё раз видит в конце сессии.

**Английский.** Словарик и озвучка через встроенный в браузер `speechSynthesis` (кнопка 🔊).

**Награды.**
* Звёзды: не больше 80 в день за задания, плюс бонусы за урок, миссию, освоение и рефлексию.
* Серия дней с «заморозкой» раз в неделю.
* 12 значков.
* Экран «Миссия выполнена» с вопросом «Как тебе было?».

**Здоровье.**
* Дневной лимит (родитель может разово добавить +15 минут).
* Тихие часы и выходные дни.
* Каждые 15 минут — перерыв-разминка на 60 секунд.

**Карта островов.** По острову на тему. Остров растёт вместе с мастерством, его можно открыть и потренироваться.

**Страница родителя.**
* Прогресс по предметам, минуты и звёзды за неделю.
* Слабые темы: мастерство ниже 60 %, 3 ошибки подряд или 2 проваленных повторения.
* Настройки и назначение навыка на завтра.

**Админка Django** для всего контента. В списке заданий есть «👁 Предпросмотр» — так задание увидит ребёнок.

**Импорт контента из JSON:**
```bash
python manage.py import_content content_samples/math_fractions.json --dry-run   # только проверка
python manage.py import_content content_samples/math_fractions.json             # импорт (атомарно)
python manage.py import_content my.json --update                                # обновить существующие ключи
```
Формат описан в ТЗ, примеры — в `content_samples/`. Файлы примеров генерирует `content_samples/build_samples.py`.

**Стартовый контент:**
* 49 заданий по математике: 4 темы, 8 навыков, у каждого есть разобранный пример и подсказки.
* 40 английских слов в 6 темах с примерами предложений, плюс навык *have got* (5 заданий).

## Что сделано заглушкой или отложено

* Шаблонные (параметризованные) задания — D-022. Пока все задания написаны вручную.
* Пошаговое решение проверяется целиком, а не по шагам.
* Нет определения усталости (GAM-14). Нет гардероба и магазина для Зубрика, нет «семейного приза».
* Нет импорта слов из CSV, нет выгрузки и удаления данных по запросу родителя.
* Вместо иллюстраций — эмодзи.
* Нет еженедельного диалога на английском. Повторение навыка даёт 1 задание вместо 2.
* Плитка «Домашка» показывается с подписью «скоро».
* Автоматическая проверка доступности (axe) не подключена.
* На PostgreSQL сайт вживую не запускался. Код от СУБД не зависит, тесты проходят на SQLite.
* ИИ-помощника, Telegram и офлайн-режима нет: они не входят в Этап 1.

## Тесты

```bash
. .venv/bin/activate
python -m pytest -q                 # 63 теста: SRS, мастерство, адаптивность, проверка ответов, интеграция
```

Сквозная проверка в браузере (нужен запущенный dev-сервер и Chrome):
```bash
python tests/e2e_walkthrough.py http://127.0.0.1:8000 ../screens   # регистрация ребёнка → диагностика → миссия → награды → родитель → админ
python tests/e2e_screens.py     http://127.0.0.1:8000 ../screens   # скриншоты отдельных экранов
```
Скрипты проверяют, что страницы не делают запросов на внешние домены и что в консоли нет ошибок JS.

## Заметки по развёртыванию (пока НЕ выполнялось)

На VPS сайт сознательно не выкладывался — это решение заказчика. Telegram-бот на сервере не затрагивается. Шаблоны лежат в `deploy/`.

1. Создать пользователя `school`, сделать `git clone` в `/srv/school-site/releases/<дата>`, поставить venv и зависимости.
2. Создать `/srv/school-site/.env` по образцу `.env.example`:
   * `SECRET_KEY`, `DEBUG=0`;
   * `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`;
   * `DATABASE_URL=postgres://...`.
3. PostgreSQL: отдельные БД и пользователь (`createuser school`, `createdb -O school school`).
4. Выполнить `python manage.py migrate && collectstatic && seed_demo` или импортировать свой контент, затем `createparent`.
5. Systemd:
   * `school-site.service` — gunicorn на unix-сокете;
   * `school-missions.timer` — 04:00 по Минску;
   * `school-backup.timer` — `pg_dump`, хранить 14 дней.
6. Nginx: server-блок из `deploy/nginx.conf` (отдельный `server_name`, не пересекается с другими сервисами), TLS через certbot.
7. Обновления делаются через `deploy/deploy.sh`: бэкап, новый релиз, миграции, переключение симлинка `current`. Для отката верните симлинк назад.

Секреты, `.env` и базы данных в git не коммитятся — см. `.gitignore`.
