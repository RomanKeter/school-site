# Журнал решений (Decision Log)

Фиксируем каждое решение по реализации сразу, как только оно принято. Формат: номер, дата, решение, причина, отклонённые альтернативы, затронутые файлы.

## D-001 — 2026-11-22
**Решение.** Структура проекта: `config/` + `apps/{accounts,content,srs,learning,missions,rewards,parents}` + `templates/` + `static/` + `tests/`.  
**Причина.** Соответствует Приложению А ТЗ; изоляция доменов упрощает тесты и поэтапное расширение (этап 2: homework/ai/notify).  
**Отклонено.** Монолитное приложение `core`; разбиение по Django apps на уровне «одна модель = один app».  
**Файлы.** `apps/*/`, `config/`, `manage.py`.

## D-002 — 2026-11-22
**Решение.** SQLite по умолчанию; PostgreSQL включается при `POSTGRES_DB` в окружении.  
**Причина.** Локальный запуск без Docker за ≤ 30 мин (AC-1-16); на VPS — PostgreSQL. ArrayField/SearchVector из ТЗ заменены на `JSONField` (совместимо с SQLite).  
**Отклонено.** Обязательный Docker Compose с Postgres даже для dev; использование только PostgreSQL.  
**Файлы.** `config/settings.py`.

## D-003 — 2026-11-22
**Решение.** Пароли — Argon2 (`Argon2PasswordHasher`); картинный пароль ребёнка — хеш последовательности из 4 кодов картинок через `make_password`.  
**Причина.** FR-AUTH-1 / FR-AUTH-2.  
**Отклонено.** PBKDF2 по умолчанию; хранение картинного пароля в открытом виде / MD5.  
**Файлы.** `config/settings.py`, `apps/accounts/models.py`.

## D-004 — 2026-11-22
**Решение.** Trusted device (доверенное устройство) — подписанная cookie `family_device` (Django signing, 180 дней), без модели `TrustedDevice` в MVP.  
**Причина.** FR-AUTH-3 достаточен без серверной таблицы; проще для одной семьи на планшете.  
**Отклонено.** Полная модель TrustedDevice из раздела 10.2.  
**Файлы.** `apps/accounts/utils.py`.

## D-005 — 2026-11-22
**Решение.** SRS-алгоритм — чистые функции в `apps/srs/algorithm.py` (`schedule`, `quality`, `new_card`); состояние — dataclass `CardState`.  
**Причина.** SR-6: 100 % покрытие ветвей тестами, без БД.  
**Отклонено.** Логика в методах модели `ReviewItem`; вызов сторонней библиотеки Anki/SM-2.  
**Файлы.** `apps/srs/algorithm.py`.

## D-006 — 2026-11-22
**Решение.** Interleaving (перемешивание) — жадный алгоритм в `apps/srs/interleave.py`: не ставить подряд две задачи одной группы, если можно.  
**Причина.** Принятое улучшение №4 педсовета.  
**Отклонено.** Полностью случайный shuffle; round-robin по предметам без учёта размера групп.  
**Файлы.** `apps/srs/interleave.py`.

## D-007 — 2026-11-22
**Решение.** Mastery — скользящее окно из 10 весов в `apps/learning/mastery.py`; пороги 0.6 / 0.8 как в разделе 7.  
**Причина.** MAS-*; чистые функции для unit-тестов.  
**Отклонено.** EMA (экспоненциальное среднее); хранение только «счётчик верных».  
**Файлы.** `apps/learning/mastery.py`.

## D-008 — 2026-11-22
**Решение.** Adaptive difficulty (подстройка сложности) — скрытое состояние `AdaptiveState` (level 1–3, серии верных/ошибок); ребёнок не видит «уровень понижен».  
**Причина.** Принятое улучшение №2.  
**Отклонено.** Elo-рейтинг; показ ребёнку «уровень сложности».  
**Файлы.** `apps/learning/adaptive.py`.

## D-009 — 2026-11-22
**Решение.** Контент MVP: модели Subject→Unit→Topic→Skill→Exercise + VocabularyWord; типы заданий MVP (choice, input, matching, letter_tiles, fraction, step_by_step и др.).  
**Причина.** Раздел 10 + каталог 5A; эталонные типы из приёмки.  
**Отклонено.** Отдельная таблица на каждый тип задания; хранение ответа внутри `payload`.  
**Файлы.** `apps/content/models.py`.

## D-010 — 2026-11-22
**Решение.** `Block` как универсальная очередь шагов миссии/урока (`queue` JSON + `position`), вместо жёстких `Lesson`/`LessonStep`/`MissionItem` из ТЗ.  
**Причина.** Упрощает MVP-плеер и сохранение прогресса (FR-MIS-2) без лишних JOIN; Lesson-структура «Вспомним→Смотри→Попробуй→Сама» кодируется видами элементов очереди.  
**Отклонено.** Полная модель Lesson/LessonStep/LessonStepExercise из 10.2 на этапе 1.  
**Файлы.** `apps/learning/models.py`.

## D-011 — 2026-11-22
**Решение.** CSP middleware запрещает внешние CDN; шрифт Nunito и HTMX — self-hosted в `static/`.  
**Причина.** AC-1-14, DS-17, приватность и доступность из Беларуси.  
**Отклонено.** Google Fonts / CDN HTMX.  
**Файлы.** `config/middleware.py`, `static/fonts/`, `static/js/htmx.min.js`.

## D-012 — 2026-11-22
**Решение.** Картинки слов и маскот Зубрик в MVP — эмодзи / простой SVG-placeholder, не полноценные иллюстрации.  
**Причина.** ТЗ допускает placeholder; контент-арт — отдельный объём; ускоряет MVP.  
**Отклонено.** Заказ SVG-иллюстраций на каждое слово до запуска кода.  
**Файлы.** `apps/content/models.py` (поле `picture`), шаблоны.

## D-013 — 2026-11-22
**Решение.** Аудио английских слов — `speechSynthesis` браузера (en-GB), без серверного TTS.  
**Причина.** Раздел 13.3 / этап 2 для серверного TTS; браузерный синтез закрывает FR-EN-1 в MVP без внешних API.  
**Отклонено.** Генерация MP3 через облачный TTS на этапе 1.  
**Файлы.** шаблоны/JS словаря и карточек слов.

## D-015 — 2026-11-22
**Решение.** Единый плеер `Block` + `player.resolve()` раздаёт шаги: worked example (разобранный пример), exercise, adaptive, word, review, celebrate. Проверка ответа — HTMX POST, сервер возвращает фрагмент обратной связи.  
**Причина.** FR-LRN-1/2: одно задание на экран, ответ проверяется только на сервере.  
**Отклонено.** SPA (одностраничное приложение) на React; проверка ответа в JS на клиенте.  
**Файлы.** `apps/learning/player.py`, `apps/learning/views.py`.

## D-016 — 2026-11-22
**Решение.** Звёзды — журнал `StarTransaction` с уникальным ключом `(child, source_type, source_id)`, потолок 80/день только для источников заданий.  
**Причина.** GAM-1, GAM-2, AC-1-08 (нет двойного начисления).  
**Отклонено.** Счётчик-поле `stars` в профиле ребёнка.  
**Файлы.** `apps/rewards/stars.py`, `apps/rewards/models.py`.

## D-017 — 2026-11-22
**Решение.** Входная диагностика (diagnostic test) — первый блок первой миссии: по 2 лёгких задания на первые 4 навыка математики + 5 слов; верный ответ ставит навыку флаг `placed` (статус «Почти»). Ребёнок видит нейтральное «Давай познакомимся».  
**Причина.** Принятое улучшение №1; не заставлять решать уже известное.  
**Отклонено.** Отдельная длинная контрольная с оценкой; адаптивный CAT-тест (computerized adaptive testing) — избыточно для MVP.  
**Файлы.** `apps/missions/builder.py`, `apps/learning/views.py`.

## D-018 — 2026-11-22
**Решение.** Миссия собирается лениво при первом входе за день (`ensure_mission`), плюс команда для таймера в 04:00 — в deploy notes.  
**Причина.** FR-MIS-1 допускает «или при первом входе за день»; не нужен воркер в dev.  
**Отклонено.** Обязательный django-q2/cron уже в MVP.  
**Файлы.** `apps/missions/builder.py`, `apps/missions/views.py`.

## D-019 — 2026-11-22
**Решение.** Импорт контента: `import_content` с `--dry-run` (откат транзакции) и `--update` (upsert по `external_key`); слова английского импортируются в том же JSON внутри темы (`words`).  
**Причина.** Раздел 12.3; один формат проще для автора контента.  
**Отклонено.** Отдельный CSV-импорт слов в MVP (оставлен на этап 2); JSON Schema-валидация каждого типа (сейчас — базовая проверка обязательных полей).  
**Файлы.** `apps/content/management/commands/import_content.py`.
