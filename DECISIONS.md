# Журнал решений (Decision Log)

Фиксируем каждое решение по реализации сразу, как только оно принято. Формат: номер, дата, решение, причина, отклонённые альтернативы, затронутые файлы.

## D-001 — 2026-11-22
**Решение.** Структура проекта: `config/` + `apps/{accounts,content,srs,learning,missions,rewards,parents}` + `templates/` + `static/` + `tests/`.  
**Причина.** Соответствует Приложению А ТЗ; изоляция доменов упрощает тесты и поэтапное расширение (этап 2: homework/ai/notify).  
**Отклонено.** Монолитное приложение `core`; разбиение по Django apps на уровне «одна модель = один app».  
**Файлы.** `apps/*/`, `config/`, `manage.py`.

## D-002 — 2026-11-22
**Решение.** SQLite по умолчанию; PostgreSQL включается при `POSTGRES_DB` в окружении.  
**Причина.** Локальный запуск без Docker за ≤ 30 мин (AC-1-16); на VPS — PostgreSQL. ArrayField/SearchVector из ТЗ заменены на `JSONField` (совместимо с SQLite).  
**Отклонено.** Обязательный Docker Compose с Postgres даже для dev; использование только PostgreSQL.  
**Файлы.** `config/settings.py`.

## D-003 — 2026-11-22
**Решение.** Пароли — Argon2 (`Argon2PasswordHasher`); картинный пароль ребёнка — хеш последовательности из 4 кодов картинок через `make_password`.  
**Причина.** FR-AUTH-1 / FR-AUTH-2.  
**Отклонено.** PBKDF2 по умолчанию; хранение картинного пароля в открытом виде / MD5.  
**Файлы.** `config/settings.py`, `apps/accounts/models.py`.

## D-004 — 2026-11-22
**Решение.** Trusted device (доверенное устройство) — подписанная cookie `family_device` (Django signing, 180 дней), без модели `TrustedDevice` в MVP.  
**Причина.** FR-AUTH-3 достаточен без серверной таблицы; проще для одной семьи на планшете.  
**Отклонено.** Полная модель TrustedDevice из раздела 10.2.  
**Файлы.** `apps/accounts/utils.py`.

## D-005 — 2026-11-22
**Решение.** SRS-алгоритм — чистые функции в `apps/srs/algorithm.py` (`schedule`, `quality`, `new_card`); состояние — dataclass `CardState`.  
**Причина.** SR-6: 100 % покрытие ветвей тестами, без БД.  
**Отклонено.** Логика в методах модели `ReviewItem`; вызов сторонней библиотеки Anki/SM-2.  
**Файлы.** `apps/srs/algorithm.py`.

## D-006 — 2026-11-22

**Причина.** Принятое улучшение №4 педсовета.  
**Отклонено.** Полностью случайный shuffle; round-robin по предметам без учёта размера групп.  
**Файлы.** `apps/srs/interleave.py`.
